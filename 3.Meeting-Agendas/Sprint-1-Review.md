## Meeting Purpose

The purpose of this meeting is to review the work planned for Sprint 1 and discuss how much of it has been completed. The team will look at the progress made, check the implemented features against their acceptance criteria, and discuss any problems or unfinished tasks.

Sprint 1 focused on the basic structure of Ehda Portal. The planned work included setting up the project, connecting the database, creating user accounts, implementing login and logout, and allowing donors to create their profiles and provide their blood type and availability.

Each developer will explain their progress and demonstrate their work where possible. After reviewing the results, the team will identify any remaining tasks and discuss what needs to be done in Sprint 2.

## Sprint 1 Goals

The main goals of Sprint 1 were to:

- Set up the project structure.
- Connect the application to the database and create the required tables.
- Implement user registration, login, and logout.
- Set up authentication and access permissions.
- Allow donors to create and update their profiles.
- Add blood type and availability information to donor profiles.
- Allow donors to change their availability status.
