# Sprint 2 — Donor Search and Map

## Sprint Information

- **Project:** Ehda Portal — Online Blood Donation Platform
- **Sprint Duration:** 4 days
- **Start Date:** 17-Oct-2026
- **End Date:** 22-Oct-2026
- **Sprint Manager:** Madina Pasun, Madina Afshar

## 1. Sprint Description

Sprint 2 focuses on helping blood seekers discover potential donors using blood type and location filters. It also covers approximate donor locations to protect privacy, map functionality for nearby donors and medical facilities, and the initial blood-request workflow. Input validation and testing will be performed alongside feature development.

## 2. Sprint Objectives

- Implement donor search by blood type.
- Allow searches based on location and distance.
- Display approximate donor locations without exposing exact home addresses.
- Protect private donor information.
- Develop an interactive map showing nearby donors and medical facilities.
- Allow blood seekers to create and send blood requests.
- Test search filters, privacy controls, and request creation.
