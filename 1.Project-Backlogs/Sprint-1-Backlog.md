# Sprint 1 — Foundation

## Sprint Information

- **Project:** Ehda Portal — Online Blood Donation Platform
- **Sprint Duration:** 5 days
- **Start Date:** 10-Oct-2026
- **End Date:** 16-Oct-2026
- **Sprint Manager:** Madina Pasun, Madina Afshar


## 1. Sprint Description

Sprint 1 focuses on establishing the technical and account-management foundation of Ehda Portal. The team will set up the project structure, establish the database connection, create the initial database tables, and implement the basic user registration and authentication features. Donor profiles, blood type information, availability status, security, and initial input validation are also included.

## 2. Sprint Objectives

- Establish the project structure and connect the application to the database.
- Implement user registration, login, and logout.
- Allow donors to create and update their profiles.
- Store donor blood type and availability information.
- Implement authentication security and role-based access.
- Validate user input and handle errors.
- Prepare initial test cases and track defects.

## 4. Expected Achievements by the End of Sprint 1

By the end of Sprint 1, the team aims to achieve the following:

- Establish the initial project structure and database connection.
- Create the initial database tables and relationships.
- Implement user registration, login, and logout.
- Provide basic authentication security and access restrictions.
- Allow donors to create and update profiles.
- Store donor blood type and availability information.
- Validate user input and display appropriate errors.
- Prepare initial test cases and document identified defects.

## 5. Sprint Deliverable

A working foundation of Ehda Portal with basic account management, donor profiles, database connectivity, and initial security controls.
