# User Stories

**Course:** Software Engineering Project  
**Project Name:** Ehda Portal: An Online Blood Donation Platform

## User Story List

| ID | User Story |
|---|---|
| #001 | As a new user, I want to create an account so that I can access the platform's features. |
| #002 | As a user, I want to log in and log out so that I can access my account securely and protect it from unauthorized access. |
| #003 | As a donor, I want to create and update my donor profile so that people who need blood can find relevant information about me. |
| #004 | As a donor, I want to specify my blood type and availability so that blood seekers can identify potential donors. |
| #005 | As a donor, I want to control my availability status so that I can indicate whether I am currently available to donate blood. |
| #006 | As a blood seeker, I want to search for donors by blood type so that I can find potential donors with the blood type I need. |
| #007 | As a blood seeker, I want to search for donors by location and distance so that I can find potential donors nearby. |
| #008 | As a user, I want to view a map of nearby donors, hospitals, and blood donation centers so that I can identify relevant locations easily. |
| #009 | As a donor, I want to share my approximate location instead of my exact home address so that I can protect my privacy. |
| #010 | As a blood seeker, I want to send a blood request to a donor so that I can ask for help when blood is needed. |
| #011 | As a donor, I want to receive notifications about blood requests so that I know when someone needs my help. |
| #012 | As a donor, I want to accept or decline a blood request so that I can decide whether I am able to respond. |
| #013 | As a blood seeker, I want to receive the donor's response to my blood request so that I know whether the donor is willing to help. |
| #014 | As a donor or blood seeker, I want to exchange messages after a request is accepted so that we can discuss the potential donation. |
| #015 | As a donor, I want to record my blood donations so that I can keep track of my donation history. |
| #016 | As a user, I want to manage my account information so that my personal information remains up to date. |
| #017 | As an administrator, I want to view and manage registered users so that I can maintain the platform properly. |
| #018 | As an administrator, I want to manage hospitals and blood donation centers so that users can access accurate information about their locations. |
| #019 | As an administrator, I want to review reported accounts and take appropriate action so that the platform remains safe. |
| #020 | As an administrator, I want to monitor and manage blood requests and platform activities so that I can help ensure the system operates properly. |
