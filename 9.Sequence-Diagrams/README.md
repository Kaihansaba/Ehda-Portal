# Sequence Diagrams

## Project: Ehda Portal — Online Blood Donation Platform

### 1. Purpose

This folder contains the UML sequence diagrams for the Ehda Portal project. Sequence diagrams illustrate the interactions between users, the application, and the database in chronological order. They help explain how the system processes user requests and performs its main functions.

### 2. System Actors and Components

The sequence diagrams may include the following actors and components:

- **Donor:** A user who can receive blood requests and respond to them.
- **Blood Seeker:** A user who searches for potential donors and sends blood requests.
- **Administrator:** A user who manages accounts and monitors platform activity.
- **Ehda Portal System:** Processes user actions and applies the system's business rules.
- **Database:** Stores and retrieves user information, donor profiles, blood requests, and other relevant records.

### 3. Planned Sequence Diagrams

The following diagrams are planned for the main system workflows:

1. **User Registration and Login:** Shows how a user submits account information and how the system validates credentials.
2. **Donor Search and Blood Request:** Shows how a seeker searches for potential donors and submits a blood request.
3. **Accepting or Declining a Blood Request:** Shows how a donor responds to a request and how the system updates its status.
4. **Notifications and Messaging:** Shows how users are notified about request updates and how messaging becomes available after request acceptance, according to the system requirements.

### 4. Design Considerations

- The diagrams should follow UML sequence diagram conventions.
- Messages should appear in chronological order.
- Interactions should reflect the documented functional requirements.
- Database interactions should represent the intended system design.
- Donor privacy must be protected, including the restriction against displaying exact home addresses to ordinary users.

### 5. Diagram Files

The completed sequence diagrams and their source files will be stored in this folder.
